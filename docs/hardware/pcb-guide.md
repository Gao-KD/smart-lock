# 用嘉立创 EDA 画门锁主板原理图和 PCB

目标：画出第一版门锁后面板主板（EFR32FG28 + 433 MHz + BLE + 电机 + 读卡接口），在嘉立创打样贴片。射频部分是唯一真正难的地方，原则是**照抄官方参考设计，不要自己发挥**。

## 0. 准备

1. 安装嘉立创 EDA 专业版（免费，有网页版和客户端），用手机号注册，和立创商城、嘉立创下单账号是同一个。
2. 下载 Silicon Labs 资料（官网 xG28 开发套件页面的 Documentation / Design Files）：
   - EFR32FG28 完整数据手册（引脚、电源、晶振要求）
   - xG28-RB4401C 射频板的原理图和 PCB 设计文件（射频、电源、晶振直接参考）
   - Series 2 硬件设计指南，以及 Sub-GHz 匹配网络和 433 MHz 相关应用笔记
3. 先拆一把买来的门锁，量后面板内腔的长、宽、可用高度和螺丝孔位置，画成板框草图。PCB 尺寸由它决定。

## 1. 新建工程和元件

1. 新建工程 `smart-lock-mainboard`，一个工程里放原理图和 PCB。
2. 放元件时先在"立创商城"库里搜型号（例如 `TPS62840`、`DRV8837`、`FM17550`）。搜得到的直接用，它自带封装和 3D 模型，下单 SMT 时也能直接匹配库存。
3. 搜不到的（EFR32FG28 很可能搜不到）自己建：
   - 符号：按数据手册引脚表画，引脚名照抄
   - 封装：QFN68 8×8 mm 0.4 mm 间距，按数据手册推荐焊盘尺寸画，中间散热焊盘要打过孔接地
   - 画完核对：引脚数、1 脚位置、焊盘尺寸，各检查一遍
4. 每个元件填好"立创商城编号"（C 开头），后面导出 BOM 能直接贴片。

## 2. 画原理图（按模块分页）

| 页 | 内容 | 要点 |
| --- | --- | --- |
| 1 电源 | 电池输入 → 防反接 → TPS62840 → 3.3 V；USB-C 应急输入；电池电压分压（MOSFET 控制通断） | 电机直接接电池，不经 DC-DC |
| 2 主控 | EFR32FG28、去耦电容、高频晶振、32.768 kHz 晶振、复位、调试口 | 去耦电容、晶振电路照抄射频板；调试口引出 SWCLK/SWDIO/RESET/VCOM |
| 3 Sub-GHz 射频 | 433 MHz 匹配网络、低通滤波、天线座或弹簧天线焊盘 | 结构照抄参考设计，元件值用 433 MHz 的；预留一个 π 型匹配位置给天线微调 |
| 4 2.4 GHz | 匹配网络 + PCB 天线 | 整块照抄射频板 |
| 5 电机 | DRV8837、电流采样电阻接 ADC、续流 | 采样电阻选 0.1–0.5 Ω |
| 6 传感器与接口 | 霍尔、微动开关、蜂鸣器、LED、FPC 到前面板（读卡、键盘）、指纹/人脸预留座 | 读卡芯片放前面板（第一版也可以先用模块飞线） |

画完运行"设计规则检查（ERC）"，把未连接引脚、电源冲突都清掉。然后发给懂射频的朋友或代理商 FAE 看一遍。代理商通常免费帮忙看原理图。

## 3. 画 PCB

1. **层数**：4 层（顶层信号 / 内层完整地 / 内层电源 / 底层信号）。射频板必须有完整地平面，2 层板很难做好。
2. **板框**：导入第 0 步量好的后面板尺寸，标出螺丝孔、电池仓、电机线、把手方轴的位置。
3. **布局顺序**：先放射频和主控，再放电源，最后放接口。
   - 匹配网络紧贴芯片的射频引脚，元件按原理图顺序排成一条线
   - 晶振紧靠芯片，下方不走其他线
   - 天线放板边，远离电池和电机；天线下方和周围按参考设计净空
   - 电机驱动和大电流走线远离射频和晶振
4. **射频走线**：50 Ω 共面波导（带地的微带线）。线宽用嘉立创的阻抗计算器，按选定的板厚和叠层算。走线短、不拐直角，两侧打一排地过孔。
5. **其他走线**：电源和电机线 ≥ 0.5 mm；芯片散热焊盘打 9–16 个地过孔；空白处铺地，并多打地过孔缝合各层地。
6. 运行"设计规则检查（DRC）"，规则选嘉立创工艺（最小线宽、线距、孔径）。
7. 看 3D 预览，检查元件高度会不会顶到锁壳。

## 4. 下单打样

1. 在嘉立创 EDA 里直接点"PCB 下单"，或导出 Gerber、BOM、坐标文件到嘉立创官网下单。
2. 板子参数：4 层，1.6 mm（或按锁壳空间选 1.2 mm），沉金（QFN 焊接更可靠），选"阻抗控制"并指定叠层，跟你计算阻抗时用的一致。
3. 贴片：选嘉立创 SMT，数量 5 套。EFR32FG28 如果嘉立创没库存，选"客供料"自己买芯片寄过去；0.4 mm 间距的 QFN 不建议手焊。
4. 工期一般 4–7 天到手（贴片件要多等几天）。

## 5. 板子到手后的调试顺序

1. 不上电，用万用表量 3.3 V、电池输入和地之间有没有短路。
2. 可调电源限流 100 mA 上电，看 3.3 V 是否正常、静态电流是否异常。
3. 用 Pro Kit 主板通过调试口连上，在 Simplicity Studio 里识别芯片、烧一个点灯程序。
4. 射频：烧 RAIL Test 示例，用 RTL-SDR 看 433 MHz 有没有发射、频偏多少；用 NanoVNA 量天线驻波，调匹配元件直到 433 MHz 附近驻波比 < 2。
5. 跑 `firmware/lock` 的固件：刷卡 → 电机动作 → 网关收到上报。
6. 用 PPK2 测睡眠电流和平均电流，对照设计文档的功耗预算（目标基础版约 71 µA）。

## 常见坑

- 自己改射频匹配或天线位置，导致距离只有几米，所以一定先照抄参考设计
- 晶振负载电容选错，导致不起振或频偏大，收发不通
- 电机和射频共地不当，导致电机一转射频就丢包，所以地平面要完整
- 分压电阻常通，导致电池几个月就漏光
- 忘了留调试口和测试点，导致板子无法烧录
